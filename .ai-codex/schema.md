# Data schemas

## Profile (src/engine.ts — the user's application)
```ts
interface Profile {
  gpa: number; schoolName: string | null;
  institution: "cc" | "public4" | "private4";
  caResident: boolean; igetc: boolean;
  standing: "sophomore" | "junior";
  major: "cs" | "engineering" | "business" | "econ" | "stem" | "social" | "humanities" | "undecided";
  ptk: boolean; honors: boolean;
  hook: "none" | "veteran" | "nontraditional";
  essay: "named" | "general" | "draft";
  ecLevel: "minimal" | "campus" | "national";
  sat: number | null;
  essayText: string; essayNamed: string[]; essayVerdict: string | null;
  courses: string[]; docs: string[];
  majorDetail: string; transferReason: string;
  gpaTrend: "upward" | "flat" | "downward";
  workHours: number; firstGen: boolean;
  activitiesText: string; awardsText: string;
}
```

## School (src/data/model.json + uc_data.json appended)
`{ id, name, rate, applicants?, admitted?, cycle?, gpa: {p25,p50,p75} (nullable for UCs), nGpa, nAdmits, majors[], coadmit[], hist[], trend[], counsel?: {typical, levers[], watchouts[], programs[], feeders?} }`
- 24 T25 schools generated by `scripts/build_model.py` from `../data/processed` (research dataset: 8,910 outcomes 2011–2026, 4,243 admits)
- 7 extra UCs from `src/data/uc_data.json` (official Fall 2026 UC admit data; UC stopped publishing GPA ranges → nulls)

## Estimate (engine output)
`{ school, p, lo, hi, tier, drivers: {text, dir: "up"|"down"|"flat"}[], thin }` — tier ∈ "TAG guarantee" | "Likely" | "Strong target" | "Target" | "Reach" | "High reach" | "Long shot"

## Directory row (public/schools.json — 4,025 IPEDS institutions)
`[name, state, kind("cc"|"public4"|"private4"), domain, city, sizeCat(0-4), admitRatePct|null]`
- Generated by `scripts/build_schools_db.py` from IPEDS HD2023 + ADM2023 (utf-8-sig!); Carnegie C21BASIC 1–14 → "cc"; freshman admit rates on 1,841 rows

## ReviewResult (src/lib/review.ts)
`{ grade, summary, strengths[], risks[], essay: {grade, notes: {quote,issue,fix}[], direction} | null, statement | null, activities: {..., reframes[]} | null, perSchool: {school, verdict, moves[]}[], actions[], generatedAt }`

## localStorage keys (all client-side; site promises nothing leaves the browser)
| Key | Contents |
|---|---|
| `tcm.profile.v1` | Profile |
| `tcm.session.v1` | Session `{name, email}` |
| `tcm.users.v1` | local accounts (SHA-256 salted hashes) |
| `tcm.apikey.v1` | user's Anthropic API key (browser-direct review mode) |
| `tcm.review.v1` | last ReviewResult |
| `tcm.appdocs.v1` | uploaded doc names/text |
| `tcm.list.v1` | My Schools tracker `{school: {status, notes}}` |
| `tcm.waitlist.v1` | pricing waitlist emails |
| `tcm.schooldomain.v1` | favicon domain overrides |
| `tcm.next.v1` (sessionStorage) | post-login redirect target, e.g. "results" |

## Env (build-time, .env.example)
`VITE_REVIEW_ENDPOINT` (e.g. `/api/review` → proxy mode) · `VITE_GOOGLE_CLIENT_ID` (enables Google login) · server-side: `ANTHROPIC_API_KEY`, `ALLOWED_ORIGIN`
