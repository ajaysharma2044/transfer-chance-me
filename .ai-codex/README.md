# .ai-codex — instant project context for AI assistants

Compact reference files in the [ai-codex](https://github.com/skibidiskib/ai-codex) format, hand-maintained for this repo (the generator's auto-detection targets Next.js/SvelteKit; this is a Vite hash-routed SPA, so these are curated instead).

Read these before exploring the codebase:

- [routes.md](routes.md) — hash routes + serverless API endpoints
- [pages.md](pages.md) — what each page does and which files it lives in
- [components.md](components.md) — shared components, brand system, motion + design rules
- [lib.md](lib.md) — function signatures for the engine and every lib module
- [schema.md](schema.md) — Profile/School/Estimate shapes, data files, localStorage keys, env vars

Keep these in sync when adding routes, components, lib exports, or storage keys.
